# Play Store listing copy — DRAFT

Draft ASO copy for Play Console's Store Listing page, in English,
German, and French (Play Console supports per-locale listings — set all
three so each shows natively rather than falling back to a translated
English listing). **Review and adjust before publishing** — these are a
strong starting point built around the keyword research already done
for this app, not final marketing copy.

Play Console's actual field limits (respected below):
- **Title:** 30 characters
- **Short description:** 80 characters
- **Full description:** 4000 characters

---

## English (en-US)

**Title** (23/30 chars)
```
Table Tennis Scoreboard
```

**Alt title to A/B test** (28/30 chars) — leans harder into a search
term ("scoreboard" alone is broad; pairing it with a second common
query term can widen match) than the plain app name above:
```
TT Scoreboard: Score Counter
```

**Short description** (69/80 chars)
```
Free table tennis scoreboard: track points, games & matches courtside
```

**Full description**
```
Table Tennis Scoreboard is the courtside companion for real table
tennis matches — singles or doubles, casual or club play. No signup,
no internet connection required, just tap to score.

KEEP SCORE THE RIGHT WAY
Official ITTF scoring rules built in: points to 11 win-by-2, deuce,
best-of-3/5/7 matches, automatic change-of-ends (including the
deciding-game switch at 5 points), and correct serve rotation for both
singles and doubles.

BUILT FOR COURTSIDE USE
- One tap per point — big, clear tap zones for each side
- Undo the last point instantly if you mis-tap
- Long-press a score to correct it without resetting the match
- Spoken score announcements after every point, so you don't have to
  look down mid-rally (can be muted anytime)
- Singles and doubles support, with custom player and team names
- Light and dark themes for indoor halls or bright outdoor play
- Works fully offline — no account, no internet connection needed

SUPPORTS ENGLISH, GERMAN & FRENCH
The whole app — scoring, voice announcements, and menus — is fully
localized in English, German, and French, auto-detected from your
device language.

FREE, WITH AN OPTIONAL ONE-TIME UPGRADE
The app is free to use, with an occasional ad. A single one-time
in-app purchase removes ads for good and unlocks exporting your match
results as text — no subscriptions, ever.

Whether you're keeping score at a club night, a school PE class, or a
casual match with friends, Table Tennis Scoreboard is a fast, focused
scoreboard built specifically for table tennis — not a generic sports
counter.
```

**Keywords covered:** table tennis scoreboard, ping pong scoreboard,
table tennis score counter, table tennis score keeper, doubles table
tennis, ITTF scoring rules.
